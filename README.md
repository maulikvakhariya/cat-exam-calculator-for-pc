# cat-exam-calculator
Unofficial Windows desktop replica of the CAT exam's on-screen calculator — practice the same click-based interface, memory keys, and basic functions used in the real exam.

A standalone Windows application that recreates the basic on-screen calculator provided during the CAT (Common Admission Test) exam. Since physical calculators aren't allowed in the exam hall, candidates use a simple virtual calculator built into the test interface — this app lets you practice with a similar tool directly on your PC, no browser required.

Features:
Basic arithmetic (add, subtract, multiply, divide)
Square root and reciprocal (1/x)
Memory keys: MS, M+, MR, MC
Mouse/click-only interaction, matching the real exam's input style
Download: See the Releases section for the latest .exe.
